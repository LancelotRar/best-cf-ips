# best-cf-ipv4
## 项目功能
- 为多个公开或开源Cloudflare优选IP项目进行**聚合&去重&加地理标注&加国旗Unicode**，每3小时更新。  
- 可接入 [cmliu/edgetunnel](https://github.com/cmliu/edgetunnel)-自定义订阅汇聚。  

## 应用效果
- 经代理客户端解析后，节点名称将显示**国家代码**以及**国旗**。
